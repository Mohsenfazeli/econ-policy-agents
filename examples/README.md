## Rules for adding an example

- Public data only, retrieved by a committed script. No hand-typed figures.
- Hypothetical questions only. Do not describe a real program, fee, company or decision.
- Generated data files stay in an ignored `outputs/` folder. Commit charts only if they are needed in the walkthrough.
- Include the QA report, with real issues found in review.
