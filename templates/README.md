# Templates

Copy a template into the request's private working folder and fill it in. Do not fill templates with real work content inside this public repo.

| Template | Used by | Used in |
| --- | --- | --- |
| [Project charter](project-charter.md) | Lead PM | [Request intake](../processes/request-intake.md) |
| [Handoff message](handoff-message.md) | Lead PM | Every task assignment |
| [Assumptions log](assumptions-log.md) | All roles; kept by Lead PM | Every standard request |
| [Risk log](risk-log.md) | Lead PM | Every standard request |
| [Data documentation card](data-documentation-card.md) | Data Engineer | Every dataset used |
| [Briefing note](briefing-note.md) | Writer | [briefing-note skill](../skills/briefing-note/SKILL.md) |
| [Decision note](decision-note.md) | Writer | [decision-note skill](../skills/decision-note/SKILL.md) |
| [QA checklist](qa-checklist.md) | QA Reviewer | [QA and sign-off](../processes/qa-and-sign-off.md) |

Conventions in every template:

- `[PLACEHOLDER: ...]` marks a field to fill in. Delete the marker when filled.
- `[UNKNOWN: ...]` marks information that could not be found. Leave it visible.
- Every template has a **Label** field (Public, Internal or Confidential).
